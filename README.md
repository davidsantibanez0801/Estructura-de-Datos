# Estructura de Datos

Repositorio de la materia **Estructura de Datos**. Aqui se van juntando todas
las tareas del curso, cada una en su propia carpeta.

## Contenido

| Carpeta | Tarea | Tema |
|---|---|---|
| [`Tarea 1 - Analisis de Redes Sociales`](./Tarea%201%20-%20Analisis%20de%20Redes%20Sociales) | Tarea 1 | Programacion Orientada a Objetos (POO): lectura de archivos, calculos estadisticos e interfaz grafica, implementado en **Python** y en **Java** |

## Organizacion

Cada carpeta de tarea es independiente y contiene su propio codigo fuente,
su archivo de datos de ejemplo, sus evidencias (capturas/PDF) y su propio
`README.md` con instrucciones especificas para ejecutarla.

```
Estructura de datos/
├── README.md                              <- este archivo
└── Tarea 1 - Analisis de Redes Sociales/
    ├── README.md
    ├── python/                            <- version en Python (tkinter)
    ├── java/                              <- version en Java (Swing)
    └── evidencias/                        <- PDFs con capturas de pantalla
```
